# 📘 English for Mom — Curso personalizado de inglés

Bienvenida a tu curso de inglés. Este repositorio es tu programa completo, personal y progresivo para aprender inglés desde cero hasta un dominio excepcional.

## 🎯 ¿Qué es esto?

Un curso diseñado específicamente para ti, que avanza paso a paso, sin prisa, repasando lo aprendido y construyendo sobre lo anterior. No es una lista de reglas para memorizar: es un sistema vivo que va creciendo unidad por unidad.

## 🚀 ¿Dónde empiezo?

Empieza aquí 👉 **[Unidad 001 — Saludos y el verbo *to be*](units/phase-01/cycle-01/unit-001.md)**

Cada unidad incluye explicación, ejemplos, vocabulario, práctica y soluciones. Tómate tu tiempo — no hay prisa.

## 🧭 ¿Cómo funciona el curso?

- El curso avanza en **fases → ciclos → unidades**.
- Cada unidad se conecta con las anteriores y prepara las siguientes — nada se enseña de forma aislada.
- Las explicaciones empiezan en español y el inglés se introduce progresivamente.
- El curso usa técnicas de aprendizaje basadas en evidencia: recuperación activa, repaso espaciado, práctica intercalada y transferencia a contextos nuevos.
- Cuando se pide **`NEXT`**, se genera la siguiente unidad real del programa (no una explicación ni un resumen) y se actualizan este índice y el roadmap.

Pasar de *"sé algunas cosas de inglés"* a poder comunicarte, desenvolverte, pensar y finalmente **usar el inglés con naturalidad** en contextos cotidianos, profesionales y técnicos.
